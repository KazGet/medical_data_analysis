# Оценка прогностической значимости расширенного протокола стресс-эхокардиографии методами машинного обучения и классической статистики

## 📌 Описание проекта
Данный проект посвящен анализу данных и построению прогностических моделей на основе расширенного протокола стресс-эхокардиографии (стресс-ЭхоКГ). 

**Цель исследования:** оценить влияние основных показателей расширенного протокола на краткосрочный и долгосрочный прогноз пациентов, сравнить качество классических статистических методов (логистическая регрессия) и современных алгоритмов машинного обучения (градиентный бустинг), а также определить оптимальные пороговые значения интегральных шкал риска.

**Целевая переменная (Target):** `FU1+2+3+4 coronary event (Death+AMI+ACS+Revasc)` — бинарный признак возникновения неблагоприятного кардиального события (`1` — событие случилось: смерть, инфаркт миокарда, острый коронарный синдром, реваскуляризация; `0` — событие отсутствует).

---

## 📊 Используемые признаки и данные

В рамках **расширенного протокола** анализировались следующие параметры:
1. `WMSI range` (индекс нарушения сегментарной сократимости) — ранжирован от 0 (хорошо) до 1 (плохо).
2. `B range` (B-линии, признаки застоя в легких) — ранжирован (0 — хорошо, 1 — плохо).
3. `LV CR range` (сократительный резерв левого желудочка) — ранжирован (0 — хорошо, 1 — плохо).
4. `CFVR range` (коронарный резерв) — ранжирован (0 — хорошо, 1 — плохо).
5. `HRR range` (резерв частоты сердечных сокращений) — ранжирован (0 — хорошо, 1 — плохо).
6. **Показатели глобальной продольной деформации (GLS)** (для которых нормы находятся в разработке): `GLS stress`, `GLS reserve`, `GLS delta`.

*Примечание по мультиколлинеарности:* В ходе предварительного анализа между `GLS reserve` и `GLS delta` была обнаружена экстремально высокая корреляция (~0.96). В связи с избыточностью данных для финального моделирования был выбран наиболее стабильный и информативный параметр — **`GLS stress`**.

---

## 🛠 Методология и Моделирование

В работе сравнивались две архитектуры моделей:
1. **Логистическая регрессия (Logistic Regression):** с применением $L_1$-регуляризации (Lasso) для автоматического отбора признаков и оценки линейных взаимосвязей.
2. **Градиентный бустинг (Gradient Boosting):** для улавливания возможных нелинейных зависимостей и сложных паттернов в данных.

Валидация моделей проводилась с помощью кросс-валидации для получения несмещенных оценок метрик.

## 📈 Результаты моделирования

### Сравнение метрик эффективности моделей (Mean ± STD)

| Метрика | Логистическая регрессия | Градиентный бустинг |
| :--- | :---: | :---: |
| **ROC-AUC** | **0.755 ± 0.049** | 0.739 ± 0.044 |
| **Accuracy** | 0.702 ± 0.042 | **0.763 ± 0.032** |
| **F1-score** | 0.538 ± 0.058 | **0.575 ± 0.051** |
| **Precision** | 0.459 ± 0.054 | **0.555 ± 0.064** |
| **Recall (Sensitivity)** | **0.654 ± 0.083** | 0.608 ± 0.087 |
| **Specificity** | 0.720 ± 0.050 | **0.820 ± 0.050** |

### 🔍 Ключевые выводы по моделям:
* **Тест Делонга (DeLong test):** Полученное значение `p-value = 0.966` указывает на отсутствие статистически значимых различий между ROC-AUC обеих моделей.
* **Линейность данных:** Градиентный бустинг не дал существенного прироста в качестве классификации. Это подтверждает, что зависимость между предикторами расширенного протокола и прогнозом носит преимущественно **линейный характер**.
* **Значимость признаков:** Обе модели единогласно выделили **`WMSI range`** и **`GLS stress`** в качестве наиболее мощных прогностических маркеров. Также весомый вклад вносят `HRR range` и `CFVR range`, в то время как `B range` и `LV CR range` показали минимальное влияние.

## 🧮 Анализ интегральных шкал риска (ABCDE Score)

Был проведен отдельный статистический анализ трех модификаций клинических шкал для поиска критической суммы баллов, при которой резко ухудшается прогноз пациента:
1. **`ABCDE score`**
2. **`ABCDE score + ECG`**
3. **`ABCDE score + ECG + angina`**

### Результаты ROC-анализа и оценки порогов:
Во всех трех шкалах прослеживается четкая монотонная связь: выше балл — выше частота сердечно-сосудистых событий.

* **ABCDE score:** При 0–2 баллах частота событий низкая (16–19%). При **≥ 3 баллах** риск скачкообразно возрастает до **~40%**, достигая ~59% на максимальных значениях.
* **ABCDE + ECG:** В диапазоне 0–2 баллов частота событий стабильна (15–16%). Начиная с **≥ 3 баллов**, частота увеличивается до **33%** и плавно растет до 61% (при 6 баллах).
* **ABCDE + ECG + angina:** Демонстрирует наиболее контрастное разделение пациентов. На низких баллах (0–2) риск минимален (10–18%). При **≥ 3 баллах** начинается лавинообразный рост вероятности исхода, доходящий до **67%**.

📌 **Итог по шкалам:** ROC-анализ согласованно определил **оптимальное пороговое значение ≥ 3 баллов** для всех трех вариантов шкал как точку перелома, разделяющую пациентов на группы низкого и высокого риска.
