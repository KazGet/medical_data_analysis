# Кардиологические данные: анализ прогностической значимости стресс-эхокардиографии

## Описание проекта
Проект направлен на оценку влияния основных показателей стандартного протокола стресс-эхокардиографии на прогноз сердечно-сосудистых событий.  
Сравниваются подходы классической статистики и машинного обучения.

## Задача исследования
**Цель:**  
Оценить, насколько параметры стресс-ЭхоКГ предсказывают неблагоприятный прогноз (события: смерть, инфаркт, ОКС, реваскуляризация).  

**Прогнозируемая переменная (таргет):**  
`FU1+2+3+4 coronary event`  
- 1 — событие произошло (плохой прогноз)  
- 0 — событий не было


# Анализ прогностической значимости показателей стресс-эхокардиографии

## Общая информация

В рамках задачи была проведена оценка прогностической значимости основных показателей стандартного протокола стресс-эхокардиографии для прогнозирования неблагоприятных коронарных событий (`FU1+2+3+4 coronary event`).

## Признаки для анализа

В анализ были включены следующие группы признаков:

### Показатели симптоматики
- `symptoms`
- `Angina range`

### Показатели ЭКГ
- `depression`
- `ECG range`

### Показатели нарушения локальной сократимости
- `WMSI stress`
- `D WMSI`
- `WMSI range`
- `log_WMSI_stress`

## Целевая переменная

В качестве целевой переменной использовался бинарный прогноз:

| Значение | Описание |
|----------|----------|
| `1` | Неблагоприятное событие произошло |
| `0` | Событие отсутствовало |

## Предварительный анализ данных

На этапе предварительного анализа было выявлено большое количество повторяющихся строк. Первоначально попытка удаления дубликатов приводила к уменьшению объема выборки примерно с 500 до 160 наблюдений и резкому ухудшению статистических результатов.

Поскольку идентификаторы пациентов отсутствовали, повторяющиеся строки нельзя было однозначно считать техническими дубликатами. Вероятно, значительная часть повторов соответствовала различным пациентам с одинаковыми клиническими характеристиками.

**Решение:** Анализ проводился на полной выборке без удаления дубликатов. После восстановления полной выборки были получены устойчивые и клинически интерпретируемые результаты.

## Результаты статистического анализа

### Ключевые выводы

Статистический анализ показал, что наиболее выраженную связь с неблагоприятным прогнозом демонстрируют **показатели нарушения локальной сократимости миокарда**.

### Наиболее значимые признаки

| Признак | Статистическая значимость | ROC-AUC |
|---------|--------------------------|---------|
| `WMSI range` | p < 0.001 | ~0.684 |
| `WMSI stress` | p < 0.001 | — |
| `log_WMSI_stress` | p < 0.001 | ~0.686 |
| `D WMSI` | p < 0.001 | ~0.681 |

### Признаки симптоматики и ЭКГ

| Признак | Статистическая значимость |
|---------|--------------------------|
| `symptoms` | p = 0.0017 |
| `Angina range` | p = 0.0435 |
| `ECG range` | p = 0.0433 |

> **Примечание:** Прогностическая ценность признаков симптоматики и ЭКГ существенно ниже по сравнению с показателями локальной сократимости.

## Анализ мультиколлинеарности

Между признаками `WMSI stress` и `log_WMSI_stress` была выявлена выраженная линейная зависимость (очень высокие значения VIF). **Данные признаки не использовались совместно в одной линейной модели.**

## Многомерный анализ

### Логистическая регрессия

**Модель с признаками:**
- `symptoms`
- `depression`
- `log_WMSI_stress`
- `D WMSI`

**Результаты (5-fold Stratified Cross-Validation):**

| Метрика | Значение |
|---------|----------|
| F1-score | ~0.52 |
| Accuracy | ~0.70 |
| Specificity | ~0.73 |
| Recall | ~0.62 |

**Наибольший вклад в модель вносили:**
1. `D WMSI`
2. `log_WMSI_stress`

---

### Модель стандартного протокола

**Признаки:**
- `WMSI range`
- `Angina range`
- `ECG range`

**Вывод:** Основная прогностическая способность модели определяется именно признаком `WMSI range`. Удаление остальных признаков практически не ухудшало качество классификации.

---

### Модель градиентного бустинга (CatBoost)

**Модель с признаками:** `symptoms`, `depression`, `log_WMSI_stress`, `D WMSI`

| Метрика | Значение |
|---------|----------|
| ROC-AUC | ~0.684 |
| Accuracy | ~0.71 |
| F1-score | ~0.52 |

**Feature importance:**

| Признак | Важность |
|---------|----------|
| `D WMSI` | ~48% |
| `log_WMSI_stress` | ~26% |
| `symptoms` | ~15% |
| `depression` | ~10% |

**Модель стандартного протокола (CatBoost):**

| Признак | Важность |
|---------|----------|
| `WMSI range` | ~94% |
| `ECG range` | минимальная |
| `Angina range` | минимальная |

## Сравнение моделей

Использование нелинейной модели градиентного бустинга **не привело к существенному улучшению качества** по сравнению с логистической регрессией. Это свидетельствует о преимущественно **линейном характере** взаимосвязи между исследуемыми признаками и прогнозом.

## Основной вывод

**Наиболее информативными предикторами** неблагоприятных коронарных событий по данным стресс-эхокардиографии являются **показатели нарушения локальной сократимости миокарда**.

Показатели симптоматики и ЭКГ обладают значительно меньшей независимой прогностической ценностью и дают лишь ограниченное улучшение качества модели.
